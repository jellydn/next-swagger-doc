## 0.4.0 - 2025-01-XX

### Added

- **Auto-Generation Feature**: Automatically generate OpenAPI documentation from Next.js API routes with minimal or no JSDoc annotations
  - Reduce JSDoc boilerplate by 60%+ while maintaining full OpenAPI compliance
  - Support for both Pages Router (`pages/api/`) and App Router (`app/api/`) patterns
  - Three operational modes:
    1. **Minimal JSDoc Mode**: Write just a summary comment, auto-generate everything else
    2. **Schema Inference Mode**: Automatic TypeScript type and Zod schema extraction
    3. **Hybrid Mode**: Mix auto-generation with explicit JSDoc for full control

- **Path Inference Engine** (`src/auto-generate/path-inference.ts`)
  - Automatic conversion of Next.js file paths to OpenAPI paths
  - Support for dynamic routes: `[id]`, `[...slug]`, `[[...slug]]`
  - Automatic path parameter extraction and schema generation
  - Multi-segment dynamic route support

- **Method Detection System** (`src/auto-generate/method-detection.ts`)
  - Automatic HTTP method detection from exported functions
  - App Router: `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`, `HEAD` exports
  - Pages Router: Default export handler analysis
  - JSDoc summary extraction from function comments
  - Support for both regular and arrow function exports

- **Schema Extraction Infrastructure** (`src/auto-generate/schema-extractor.ts`)
  - TypeScript type to OpenAPI schema conversion using TypeScript Compiler API
  - Zod schema to OpenAPI conversion using `@asteasolutions/zod-to-openapi`
  - Support for primitive types, objects, arrays, unions, intersections, and generic types
  - Automatic response schema inference from function return types
  - Request body schema extraction from function parameters

- **Hybrid Documentation Mode** (`src/auto-generate/merger.ts`)
  - Deep merging of auto-generated routes with explicit JSDoc
  - Explicit JSDoc takes precedence over auto-generated values
  - Field-level merging for parameters (by name) and responses (by status code)
  - Conflict detection and resolution
  - Validation of merged route completeness

- **Configuration System** (`src/auto-generate/config.ts`)
  - Comprehensive `AutoGenerateConfig` interface with validation
  - Opt-in design (disabled by default for backward compatibility)
  - Configurable router types, schema extraction, and performance settings
  - File exclusion patterns for fine-grained control
  - Performance tuning options (caching, parallelism, timeouts)

### Changed

- **BREAKING**: `createSwaggerSpec` is now async to support schema extraction
  - Migration: `const spec = createSwaggerSpec({...})` → `const spec = await createSwaggerSpec({...})`
  - Affects all usage patterns - update your code to use `await`
- **BREAKING**: `withSwagger` middleware now uses async `createSwaggerSpec` internally
  - No code changes required for users, but response time may vary during schema extraction

### Fixed

- Improved error handling for malformed API routes
- Better handling of edge cases in dynamic route parameter extraction
- Enhanced type safety with strict TypeScript checking throughout auto-generation modules
