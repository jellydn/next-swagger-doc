## 0.5.0 - 2026-08-26

Stable release of 0.4.2-beta.0.

### Added

- Generate basic OpenAPI operations from App Router `route` files (`autoDoc`)
- Load a prebuilt spec with `specFile` and write one with `outputFile` (standalone output)
- Next.js 16 example app (`examples/next16-app`)
- Parse exported HTTP handlers with `es-module-lexer`

### Fixed

- Skip globbing `.next` during Next.js production builds (Vercel `export-detail.json` ENOENT)

### Changed

- Document `swagger-ui-react` Strict Mode warnings and load it with `next/dynamic`
